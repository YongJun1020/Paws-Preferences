# Paws & Preferences 🐱

A fun React app where you swipe to find your purr-fect match!
## Features

- Swipe right to like cats 😻
- Swipe left to pass on cats 😿
- Filter cats by tags (cute, fluffy, etc.)
- View your liked cats in the summary
- Undo your last swipe
- Keep track of your swiping history

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Tech Stack

- React
- TypeScript
- Framer Motion
- Tailwind CSS
- Vite
