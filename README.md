# Paws & Preferences 🐱

**Paws & Preferences** is a fun React web app where users swipe through adorable cats to find their **purr-fect match**. Inspired by swipe-based apps, users can like, skip, filter, and review their favorite cats in an interactive UI.

## 🌐 Live Demo

Hosted on GitHub Pages:
https://yongjun1020.github.io/Paws-Preferences/

## 📂 GitHub Repository

Source code:
https://github.com/YongJun1020/Paws-Preferences

---

## ✨ Features

* 😻 **Swipe Right to Like** — Save cats you love
* 😿 **Swipe Left to Skip** — Pass on cats you're not interested in
* 🏷️ **Tag Filtering** — Filter cats by tags (cute, fluffy, playful, etc.)
* ❤️ **Liked Cats Summary** — View all cats you've liked
* ↩️ **Undo Swipe** — Reverse your last swipe action
* 📜 **Swipe History** — Keep track of your interactions

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YongJun1020/Paws-Preferences.git
cd Paws-Preferences
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start development server

```bash
npm run dev
```

### 4. Build for production

```bash
npm run build
```

## 📦 Deployment

This project is deployed using **GitHub Pages**.

To redeploy the site:
